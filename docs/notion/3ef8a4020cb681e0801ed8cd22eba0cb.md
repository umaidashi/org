# 基本方針
Chat/RoomはUI都合ではなくCore Domainの第一級オブジェクトとする。
同じAgentとも複数Roomを持てる。
例：
- CTO / Tabli architecture
- CTO / Agent runtime
- CTO / 雑談・相談
# Room types
- Direct Room：Human + Agent
- Group Room：Human + 複数Agent
- Agent Room：Agent + Agent
- Task Room：特定Taskに紐づく一時Room
# Data model
```typescript
Room {
  id
  title
  type
  activationPolicy
  participants[]
  createdAt
  archivedAt?
}

Message {
  id
  roomId
  sender
  content
  replyTo?
  metadata
  createdAt
}
```
# Room / Session / Memoryを分離
- **Agent** = 誰か
- **Room** = どこで話しているか
- **Session** = Claude/Codexの実行セッション
- **Memory** = 何を覚えているか
Claude/Codex session IDをRoom IDにしない。
Runtime sessionが壊れても、Room messages + Room summary + Agent memoryから新規Sessionを再構築できるようにする。
# activation_policy
- mention_only
- coordinator
- all
- rule_based
デフォルトは `coordinator`。
