# Control Plane / Execution Plane
```plain text
Control Plane
├─ Agents
├─ Rooms
├─ Tasks
├─ Events
├─ Subscriptions
├─ Permissions
└─ State

Execution Plane
├─ Claude Code
├─ Codex CLI
├─ Sandbox
├─ n8n
└─ shell
```
# AgentRuntime
```typescript
interface AgentRuntime {
  start(agent, input)
  send(sessionId, message)
  resume(sessionId)
  stop(sessionId)
}
```
Adapters：
- ClaudeCodeRuntime
- CodexRuntime
- OpenAIRuntime
- AnthropicRuntime
Agent IdentityとRuntime Sessionは分離する。
# SandboxRuntime
Agentは永続、作業机はephemeral。
```plain text
Task
 ↓
Sandbox.create()
 ↓
repo checkout / mount
 ↓
必要なcredentialsだけinject
 ↓
Claude / Codex / shell
 ↓
artifact回収
 ↓
destroy
```
Adapters：
- LocalProcessSandbox
- DockerSandbox
- PodmanSandbox
- SSHRemoteSandbox
- CloudSandbox
# WorkflowRuntime
WorkflowもAgentから分離する。
```typescript
interface WorkflowRuntime {
  invoke(workflowId, input)
  status(executionId)
  cancel(executionId)
}
```
初期Adapterはn8n。
将来：
- Local workflow
- Temporal
- Windmill
決定論的な作業手順はWorkflowへ寄せ、Agentに手順を暗記させない。
