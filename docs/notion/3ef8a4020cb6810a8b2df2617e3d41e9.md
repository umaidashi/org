# Agentの定義
Agentはモデルそのものではなく、永続するIdentityとRoleを持つ論理オブジェクト。
```typescript
Agent {
  id
  name
  role
  reportsTo?
  runtime
  capabilities
  permissions
  memoryPolicy
}
```
`CTO = persona / role`、`Codex = runtime` と分離する。
# 組織
最上位はChief of Staff。Founderとの主インターフェースを担い、専門Agentへ委譲する。
```plain text
Founder
  ↓
Chief of Staff
  ├─ CTO
  ├─ Researcher
  ├─ Sales
  ├─ Compliance
  └─ Customer Success
```
# Coordinator policy
複数Agent Roomでは **coordinator方式** を標準とする。
- 人間の発言で全Agentを一斉起動しない
- ChiefなどCoordinatorだけを起動する
- Coordinatorが必要なAgentだけ呼ぶ
- 直接@mentionされたAgentは例外的に直接起動可能
# A2A
自由会話を基盤にせず、typed messageを中心にする。
```typescript
Message {
  id
  from
  to
  type
  taskId?
  payload
  correlationId?
}
```
主なtype：
- delegate
- request
- result
- question
- decision
- blocker
- cancel
外部A2A標準への対応はAdapterとして後から追加する。
