# Event
Eventは「何かが起きた」という事実。
例：
- github.pull_request.opened
- linear.issue.created
- gmail.message.received
- workflow.completed
- agent.blocked
- schedule.daily_0900
Taskは「誰かが何かをする」。EventとTaskを分ける。
```plain text
Event
 ↓
Rule / Subscription
 ↓
Task creation or Workflow invocation
 ↓
Agent execution
 ↓
New Event
```
# Pub/Sub
Publisherは受信者を知らずEventをpublishする。
Subscriberはevent patternを購読する。
```plain text
github.pr.opened
      ↓
   Event Bus
   ├─ CTO
   ├─ Reviewer
   └─ Audit
```
# Subscription model
```typescript
Subscription {
  id
  subscriberType // agent | workflow
  subscriberId
  eventPattern
  filter?
  enabled
}
```
Agentが常時LLMプロセスとして待つ必要はない。
```plain text
event
 ↓
subscription match
 ↓
task作成
 ↓
agent runtime起動
 ↓
処理
 ↓
agent停止
```
# Trigger
- schedule
- webhook
- event
- manual
- internal event
# Local default
最初はSQLite/Postgres backed event log + daemon workerでよい。
将来Adapterとして：
- NATS
- Redis Streams
- Kafka
- Cloud Pub/Sub
- Cloudflare Queues
を選択可能にする。
