# Vision
ローカルファーストで、複数の永続Agentが役割を持ち、イベントやスケジュールを契機に自律的に動く「AI Company Kernel」を作る。
GUIに依存せず、CLIを主操作面、必要な可視化だけTUIで提供する。
# 設計原則
- **Runtime agnostic**：Claude Code / Codex / API modelなどを差し替え可能にする
- **Local first**：常駐daemon、ローカルDB、ローカルsandboxで成立する
- **Ports & Adapters**：Agent / Memory / Task / Workflow / Event / Sandboxをすべて抽象化する
- **Event driven**：人間の指示だけでなくEvent / Scheduleで自律起動する
- **Deterministic core**：Task・Event・Policy・Workflowを中心にし、LLMは判断が必要な箇所に限定する
- **Persistent identity, ephemeral execution**：Agentは永続、作業環境は必要に応じて一時生成
- **History is truth**：実行履歴・会話・イベントは原本として保存し、Memoryはそこから生成する
