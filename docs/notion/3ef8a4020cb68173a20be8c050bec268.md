# MVP Goal
「イベントで永続Agentが起き、必要なMemoryを読み、Taskを作成・実行し、別Agentやn8n workflowへ委譲できる」状態。
# Phase 1｜Kernel
- Agent
- Room / Message
- Task / ExecutionTask
- Event / Subscription
- SQLite store
- local daemon
- CLI
# Phase 2｜Agent Runtime
- Claude Code adapter
- Codex CLI adapter
- session start / resume / stop
- Role / instruction injection
# Phase 3｜Memory
- Projected Typed Memory
- scope
- semantic / episodic / procedural / relational
- extraction
- supersede
- context builder
# Phase 4｜Autonomy
- scheduler
- local event bus
- subscription matching
- Agent wake-up
- coordinator Room policy
# Phase 5｜Execution
- Docker sandbox
- artifact collection
- n8n WorkflowRuntime adapter
# Phase 6｜External adapters
- Linear TaskProvider
- GitHub events
- Notion knowledge/docs
- NATS/Redis adapter if necessary
# MVPで作らない
- 重いGUI
- 独自LLM provider
- 独自vector DB
- Kafka等の大規模message infrastructure
- 独自Workflow designer
- 完全なA2A protocol実装
# デフォルト構成
```yaml
storage: sqlite

agent_runtime:
  - claude-code
  - codex

memory:
  provider: projected

task:
  provider: local

workflow:
  provider: n8n

event_bus:
  provider: local

sandbox:
  provider: docker

ui:
  cli: true
  tui: true
```
MVP後もCore Domainを変えず、Adapterの差し替えでLocal / Cloud / SaaSのどこでも実行できることを目標とする。
