# 操作面
GUIを作り込まず、CLIを第一級インターフェースにする。
```bash
org daemon

org agent list
org agent create cto --runtime codex
org agent send chief "今週の優先順位を整理して"

org room list
org room create "architecture" --with chief,cto,researcher
org room open architecture

org task list
org task assign TASK-123 cto

org workflow run implement-issue --input issue=123

org event publish github.pr.opened --data '{"pr":123}'

org sandbox list
org logs tail cto

org tui
```
# TUI
TUIは監視と対話に絞る。
```plain text
Agents
● Chief      idle
● CTO        working
○ Researcher sleeping

Rooms
# founder-chief
# architecture
# research

Tasks
#123 implementing
#124 blocked

Events
github.pr.opened
workflow.completed
```
# Local daemon
daemonが以下を担う。
- scheduler
- event polling / subscription
- runtime process管理
- execution state
- retry / timeout
- Agent wake-up
- local API/socket
CLIとTUIはdaemonへ接続する薄いclientとする。
