# デフォルト方式
今回のデフォルトMemoryを **Projected Typed Memory** と呼ぶ。
> immutable historyを真実とし、Memoryは履歴から生成されるprojectionとして扱う。
# Memory Types
- **Semantic**：事実・知識
- **Episodic**：過去に何をしたか
- **Procedural**：どう仕事するか
- **Relational**：Agent・Founder・組織との関係や好み
# Source of truth
以下はimmutable historyとして保持する。
- Messages
- Task executions
- Workflow executions
- Decisions
- Events
- Artifacts
Memoryはこれらから抽出する。
```plain text
Immutable History
      ↓
Memory Candidate Extraction
      ↓
Deduplicate / Conflict detection
      ↓
Typed Memory Projection
      ↓
Active Memory
      ↓
Context Retrieval
```
# Memory model
```typescript
Memory {
  id
  type
  scope
  content
  status // active | superseded | invalidated
  confidence
  validFrom?
  validUntil?
  sourceRefs[]
  supersedes?
}
```
# Scope
- global
- company
- department:engineering
- project:Example Project
- agent:cto
- room:xxx
- task:xxx
Agent起動時は現在のscopeに関係するMemoryだけを選択的にretrieveする。
# 更新
古いMemoryを削除・上書きしない。
例：
```plain text
M1: Example Project DBはD1を検討中
status = superseded

M2: Example Project DBはPostgresを採用
status = active
supersedes = M1
```
# Retrieval
最初はVector DBを必須にしない。
優先順：
1. scope
2. type
3. tags/entity
4. recency
5. importance
6. full-text
7. vector similarity / rerank（必要になったら）
# Port化
Memoryは研究・思想差が大きいため差し替え可能にする。
```plain text
MemoryProvider
MemoryExtractor
MemoryRetriever
MemoryConsolidator
ContextBuilder
```
Preset候補：
- projected（default）
- mem0
- letta
- langmem
ProviderとPolicyも分離する。
```yaml
memory:
  provider: projected
  policy:
    extraction: conservative
    consolidation: nightly
    retrieval: scoped-relevance
```
